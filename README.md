# Black Eye Fight News — International Combat Sports

A public, continuously updated combat-sports website covering boxing, MMA, wrestling and submission grappling.

- **Latest news:** source-linked boxing and MMA headlines, refreshed throughout the day.
- **Upcoming cards:** confirmed bouts, fighter records, event posters, undercards and schedules.
- **Results:** live and completed event cards, linked outcomes and available Australian-accessible highlights.
- **Champions and fighter scout:** championship tables and profiles, with properly framed and attributed photography.
- **Fight Talk:** directly sourced posts and exchanges across available social platforms, with a live/relevant view and four-week highlights.
- **Fight Film:** sourced finish and highlight footage, separated by discipline.
- **Installable app:** PWA assets and Capacitor starter; see [the mobile app guide](docs/mobile-app.md).

Deployment: Render Static Site, branch `main`, build command `echo 'Ready'`, publish path `.`, auto-deploy enabled.

**Editorial rules:** verify records, quotes, dates, posts and rights to embedded media. Never fabricate information or claim an API platform is connected unless authenticated and approved. Keep private publications and personal delivery details out of this public repository and deployment.
