## 2026-11-19
- Finished boxing cards (any promotion) move into Results from Boxerbook's results list, read with the owner's free API key (GitHub secret `BOXERBOOK_KEU`; `BOXERBOOK_API_KEY` and `BOXERBOOK_KEY` also accepted). Boxerbook's terms allow personal, non-commercial sites to show results with the credit "Data from Boxerbook (https://boxerbook.com)" and a link to each bout's page; bulk copying is not allowed. So one list request per run, only the bouts of cards already on BEFN are stored, and every bout links its boxerbook.com page. Boxerbook has no scorecards or punch stats. Records like "14-0 (8 KOs)" are now read as 14-0-0, not 14-0-8. — Owner — PR for branch feat/boxing-results-boxerbook-20261119.
- PFL results switched to the Wikipedia event articles: ESPN's feed refuses requests from GitHub's servers (HTTP 403) and is not worked around. Fighter names are matched allowing small spelling differences (Sergei/Sergey). — Claude, owner-approved source policy — PR for branch fix/pfl-results-from-wikipedia-20261119.
- Finished PFL cards move into Results from ESPN's public fight-center feed; ONE Championship and Cage Warriors from the Wikipedia season pages (CC BY-SA, linked as the source). Four runs a day, no keys. BigBalls was assessed and not used (boxing data stops at 1 Aug 2026; MMA not on the plan). Boxing will use Boxerbook once the owner adds `BOXERBOOK_API_KEY`. — Owner — PR for branch feat/import-pfl-one-cw-results-20261119.

A twice-daily job downloads each recorded poster once, stores a resized WebP in `assets/img/posters/`, and records source, credit and rights in `data/poster-register.json`; pages prefer these BEFN-hosted copies. Originals are not committed. — Owner — PR for branch feat/cache-official-posters-20261119.
- UFCalendar Hobby plan cancelled; the rich backfill and its watcher workflows are disabled (data already collected stays). — Owner — Actions settings.
- Finished UFC cards move into Results automatically from the free UFCStats CSV export (Greco1899/scrape_ufc_stats), checked twice a day; no paid UFCalendar calls. Other promotions still need a source. The owner is cancelling the UFCalendar Hobby plan; Cito's two free keys (500 requests a month each) cover UFC stats. — Owner — PR for branch feat/import-finished-ufc-results-20261119.
- Render publishes a built `dist/` folder of reader files only, not the repository root. Research archives, provider caches, docs and workflows were downloadable from the live site. — Owner approved — PR for branch fix/publish-reader-files-only-20261119; owner changes the Render build command and publish directory after merge.
