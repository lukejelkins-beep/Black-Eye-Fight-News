# BEFN design and working files

Start here. These files are the shared memory for how Black Eye Fight News is designed and built, so any session (Claude, Codex, a person) picks up the same direction instead of rediscovering it.

| File | What it is | Update it when |
|---|---|---|
| [DIRECTION.md](DIRECTION.md) | What BEFN should look and feel like: principles, tokens, layout rules, what we will not do | The owner changes the look or approves a new pattern |
| [WORKING-AGREEMENT.md](WORKING-AGREEMENT.md) | How we work: roles, approvals, previews, definition of done | The process changes |
| [IMAGE-GUIDE.md](IMAGE-GUIDE.md) | Where images come from, how they are stored, sized and credited | The image pipeline or a rights decision changes |
| [REVIEW-2026-11-17.md](REVIEW-2026-11-17.md) | Full review of the live site and the prioritised roadmap | A roadmap item ships (tick it) |
| [REVIEW-2026-11-28.md](REVIEW-2026-11-28.md) | Clicks and space review; what the leaderboards change did and the proposals left for the owner | A proposal is approved or built |
| [HANDOVER-2026-11-24-cutouts-faceoff.md](HANDOVER-2026-11-24-cutouts-faceoff.md) | Handover from the 24 Nov cutouts / face-off / profile band / flags chat: what shipped, how it fits, open items | The next chat picks it up or an open item is closed |
| [DECISIONS.md](DECISIONS.md) | Dated log of decisions, newest first | Any decision is made, however small |
| [BOXING-IMAGE-CACHE-SCOPE.md](BOXING-IMAGE-CACHE-SCOPE.md) | Proposal for a boxing photo library, with the priority list in `boxing-photo-priority.csv` | The owner answers its rights questions, or the library starts |

Rules for these files: short, specific, dated. If a rule here conflicts with `AGENTS.md` on data, certification or release safety, `AGENTS.md` wins.
