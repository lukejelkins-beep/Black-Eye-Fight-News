# Claude instructions for BEFN

- Follow `AGENTS.md` first: it holds the data, certification, budget and release rules. They apply to every tool, not only Codex.
- Before visual or front-end work read `docs/design/README.md` and the files it lists.
- Nothing is merged to `main`, or to the Sumo preview branch, until the owner says "Merge N". Open a PR, say how it was verified and what was not, then wait.
- Check visual changes in a real browser at 390 px and 1280 px, not only with tests.
- Record decisions in `docs/design/DECISIONS.md`.
